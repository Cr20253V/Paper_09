## 4. 128 步历史窗口的实验设置公式

### 4.1 建议公式

为使公式同时反映速度、坡度、整车质量和旋转部件惯量，可先定义等效平动质量：

```math
m_{eff}=m+\frac{n_a(I_w+I_m i_g^2)}{r^2},
```

其中 `n_a=2` 为主动驱动车轮数，`I_w` 为单轮转动惯量，`I_m` 为电机转子惯量，`i_g` 为减速比，`r` 为车轮半径。代表性坡度产生的重力分量为

```math
F_\theta(\theta_c)=mg|\sin\theta_c|.
```

将需要覆盖的特征速度变化写为

```math
\Delta v_{char}=\eta_v v_c,
```

其中 `v_c` 是实验运行包络中的代表速度，`eta_v` 应由实验速度变化范围或预先定义的可辨识速度变化比例确定，不能为了得到 128 而反向拟合。坡度响应时间和原始窗口长度为

```math
T_\theta=\frac{m_{eff}\Delta v_{char}}{F_\theta(\theta_c)},
\qquad
L_{raw}=\left\lceil\frac{T_\theta}{T_s}\right\rceil.
```

最后将 `L_raw` 向上映射到网络实现支持的长度：

```math
L=\mathcal Q(L_{raw}),
```

其中 `Q(.)` 可定义为向上选择最近的候选实现长度或二进制友好长度。最终必须由实际速度包络和代表性坡度算出 `L_raw` 后再说明为什么选择 `L=128`。

### 4.2 当前已知参数

来自 `src/core/parameters.m`：

| 参数 | 数值 |
|---|---:|
| `T_s` | 0.01 s |
| `m` | 200 kg |
| `r` | 0.15 m |
| `I_w` | 0.0135 kg m^2 |
| `I_m` | 1.77e-3 kg m^2 |
| `i_g` | 10 |
| `n_a` | 2 |
| `m_eff` | 约 216.93 kg |

需要在最终实验设置中确定：

1. `v_c` 或 `[v_min,v_max]` 应取训练与测试路径的冻结运行包络；
2. `theta_c` 应是预先定义的代表性/最低控制相关坡度，而不是为 128 反推的数值；
3. `eta_v` 或 `Delta v_char` 的工程定义；
4. `L_raw` 的数值结果及 `Q(.)` 的固定规则；
5. 最终说明 `L=128` 对应 1.28 s，且轻量 ModernTCN 的 5 个 `K=31` 残差块具有 151 点名义感受野，能够覆盖该输入窗口。

### 4.3 物理解释边界

若只考虑坡度重力分量，`F_theta=mg sin(theta)` 与平动惯性 `m Delta v` 中的质量会大体抵消，因此窗口长度对整车质量的依赖本来就较弱。引入 `m_eff` 后，质量和旋转惯量通过 `m_eff/m` 保留在响应时间中。论文不应夸大“车辆越重就必然需要越长窗口”，更准确的说法是：窗口主要受代表速度变化尺度和坡度大小影响，质量/转动惯量通过等效惯性进行修正。

