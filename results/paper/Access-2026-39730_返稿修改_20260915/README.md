# Access-2026-39730 返稿修改工作区

本目录用于 IEEE Access 稿件 `Access-2026-39730` 的返修、一次性重新投稿和证据归档。

## 目录结构

- `00_原始返稿材料/`：2026-09-15 决定邮件、审稿人附件和 IEEE 官方模板。原始文件不得覆盖。
- `01_返稿意见与指引/`：中文返稿意见与修改指引，已逐页检查。
- `02_逐条回复/`：后续存放逐条回复信、意见跟踪表和证据索引。
- `03_修改稿/`：后续存放黄色高亮稿、干净稿、LaTeX 源文件和编译产物。
- `04_补充实验与结果/`：后续存放模型审计、补充实验、统计结果和复现记录。

## 工作原则

1. 每条意见使用唯一编号：`R1-C01` 至 `R1-C06`、`R2-C01` 至 `R2-C35`。
2. 正式回复必须包含 reviewer concern、author response 和 author action。
3. 修改实验或论文时保留配置、随机种子、原始结果、汇总脚本和运行日志。
4. 未完成实验前不得在回复信中承诺结果；无法完成的要求应有证据充分的限制说明。
5. 原始返稿材料的完整性以 `REVISION_MATERIALS_SHA256.csv` 为准。
