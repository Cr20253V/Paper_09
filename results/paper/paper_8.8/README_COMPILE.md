# Portable submission package

Main file: `paper.tex`

Compile with pdfLaTeX and BibTeX:

```text
pdflatex paper.tex
bibtex paper
pdflatex paper.tex
pdflatex paper.tex
```

For TeXstudio, set `paper.tex` as the main document and use pdfLaTeX/BibTeX.
For Overleaf, upload the contents of this folder as a new project and set `paper.tex` as the main document.
